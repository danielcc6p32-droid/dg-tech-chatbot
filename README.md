
# DG Tech Chatbot

Chatbot de atendimento virtual desenvolvido com Node.js, Express, HTML, CSS e JavaScript.

Projeto criado para estudos, desenvolvimento de habilidades e demonstracao profissional.

## Sobre o projeto

O DG Tech Chatbot simula um sistema de atendimento automatizado voltado para empresas e usuarios de tecnologia.

O sistema oferece uma interface web interativa, permitindo que o usuario selecione uma area de atendimento e continue a conversa sem perder o contexto.

## Funcionalidades

- Interface web responsiva
- Atendimento automatizado
- Memoria de contexto por conversa
- API REST com Node.js e Express
- Validacao das mensagens recebidas
- Integracao experimental com WhatsApp Cloud API
- Webhook com validacao de assinatura HMAC
- Atendimento demonstrativo sem dependencia do WhatsApp

## Areas de atendimento

1. Suporte tecnico
2. Consultoria em infraestrutura de TI
3. Desenvolvimento de sistemas
4. Atendimento humano simulado

## Tecnologias utilizadas

- Node.js
- JavaScript
- Express.js
- HTML5
- CSS3
- Git e GitHub
- WhatsApp Cloud API
- Cloudflare Tunnel

## Estrutura do projeto

- public/index.html - Interface do chatbot
- public/style.css - Estilizacao da interface
- public/script.js - Interacao com o usuario
- server.js - Servidor e API
- .env.example - Exemplo de configuracao
- package.json - Dependencias e scripts

## Como executar

Clone o repositorio e acesse a pasta do projeto.

Instale as dependencias:

npm install

Inicie o servidor:

npm start

Acesse no navegador:

http://localhost:3000

## Integracao com WhatsApp

O projeto inclui uma integracao experimental com a API oficial do WhatsApp Business.

A utilizacao real depende das permissoes e da habilitacao da conta pela Meta.

A demonstracao web funciona independentemente dessa integracao.

Demonstrar conhecimentos em desenvolvimento web, integracao de APIs, backend Node.js, comunicacao HTTP e organizacao de projetos.
